Wat je net zag

Start je Claude Code vanuit deze map, dan leest het eerst de vaste instructies en opent het daarna de relevante gidsen, projecten en research. Zo past het antwoord bij je werkplaats in plaats van bij een willekeurige printer of arm.

Dan komt de belangrijke stap: test het antwoord. Alleen een bevestigde ontdekking hoort als bestand op de plank. Vraag Claude waar hij thuishoort, lees de wijziging na en maak een kopie van je lokale map of publiceer hem later met GitHub.

Eerlijk erbij: een chat bewaart de repository niet automatisch. Claude Code kan een bestand voorstellen of lokaal wijzigen; jij controleert of het klopt. De volledige eerste installatie staat in docs/claude-usage-guide.md.
