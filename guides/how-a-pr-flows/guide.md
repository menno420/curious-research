# Hoe een wijziging duurzaam wordt — optionele ontwikkelaarsroute

De maker hoeft geen pull requests te begrijpen om deze repository met Claude te gebruiken. De
actuele gebruikersworkflow staat in:

- [Claude gebruiken met deze repository](../../docs/claude-usage-guide.md)
- [Begin hier](../begin-hier/guide.md)

Voor wie later wél via GitHub wil publiceren geldt compact:

1. werk op een aparte branch;
2. bekijk iedere bestandswijziging;
3. voer de repositorycontrole uit;
4. open een pull request;
5. merge alleen na een groene controle en menselijke beoordeling.

Chatinhoud wordt hierdoor niet automatisch kennis: alleen gecontroleerde bestandswijzigingen
komen in de repository terecht.
