Installeer voor de volgende taak, niet voor de hele toekomst

Ieder programma krijgt één concrete ketentest. Voor vragen via website + chat is nu geen lokale installatie nodig.

💬Website + chatgeen installatie
🖨️Bambu Studioslice + Preview
🔌Arduino IDEverify + upload
📐OpenSCADbestaande .scad
🐍Pythonlokale projecttool

Stopcriterium

  • Claude of ChatGPT noemt na gedeelde context de juiste werkplaats en verzint ontbrekende hardware niet.
  • Bambu Studio toont een geslicede plaat in Preview.
  • Arduino IDE uploadt een actuatorloze test en toont Serial-uitvoer.
  • OpenSCAD exporteert alleen wanneer een bestaand SCAD-project dat vraagt.
  • Lokale Python komt pas bij een lokale `.py`-tool; Fusion-scripts draaien in Fusion.
