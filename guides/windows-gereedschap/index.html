Windows-gereedschap

Alles hieronder is gratis en draait op Windows 10 en 11. Het belangrijkste eerst: je hebt hier niets van nodig om te beginnen. Vragen stellen aan Claude werkt gewoon in je browser.

Wat wil je gaan doen?

De programma's

Heb je waarschijnlijk al

1 · Je slicer

De slicer (= het programma dat een 3D-model omzet in laagjes en in de instructies die je printer echt uitvoert) kwam waarschijnlijk mee met je printer. Gebruik gewoon die.

Weet je niet welke je hebt, of wil je een andere:

Bambu Studio (voor Bambu-printers) · PrusaSlicer · Ultimaker Cura (die laatste twee werken met bijna elke printer)

Klaar als: je kunt een .stl- of .3mf-bestand openen en op Slice klikken.

Nodig zodra je iets uit deze map wilt printen

2 · OpenSCAD

De ontwerpen in projects/ zijn .scad-bestanden: CAD waarbij het model een stukje tekst is in plaats van iets wat je met de muis boetseert. Precies daarom kan Claude ze voor je schrijven en aanpassen.

openscad.org/downloads.html → kies onder Windows de Installer (x86-64).

  1. Open een .scad-bestand.
  2. Bovenin staan de instellingen. Verander gerust een getal.
  3. Druk op F6 (Render — hij rekent het echte model uit; duurt even).
  4. Klik File → Export → Export as STL… en sla het op.
  5. Dat .stl-bestand open je in je slicer, en printen maar.

Waarom dit leuk is: verander één getal bovenin, druk op F6, en je hebt een ander object. Dat is de makkelijkste manier om te zien wat "parametrisch ontwerpen" betekent.

Nodig zodra je met de arm of een sensor werkt

3 · Arduino IDE

Nodig zodra je iets uit projects/ naar een Arduino wilt sturen. Er liggen al kant-en-klare sketches klaar (sketch = zo heet een Arduino-programmaatje).

arduino.cc/en/software → kies Windows Win 10 and newer, 64 bits (de gewone installer, niet de "ZIP file").

  1. Installeer en start het programma.
  2. Steek je Arduino in de USB-poort.
  3. Bovenin staat een uitklapmenu "Select Board" — klik erop en kies je bordje.
  4. Open een sketch uit deze map.
  5. Klik op het pijltje naar rechts (→) linksboven om hem te versturen.

Klaar als: onderin staat "Done uploading" in plaats van een rode foutmelding.

⚠️ Lees dit vóór je een servo aansluit Servo's krijgen hun eigen voeding van 5–6 volt, met gedeelde massa en een schakelaar die je kunt bereiken. Nooit via de 5V-pin van de Arduino — die levert te weinig stroom en je Arduino kan eraan kapotgaan.
Puur gemak

4 · 7-Zip en Notepad++

7-Zip (kies Windows x64 bij de bovenste .exe) pakt gedownloade mappen uit. Windows kan zelf ook ZIP-bestanden uitpakken, dus dit is puur gemak.

Notepad++ (nieuwste versie → Installer 64-bit x64) laat je even in een .ino of .scad kijken zonder een heel programma te openen. Kladblok werkt ook.

Wat je expliciet niet hoeft te installeren

Git — hier lopen veel mensen op vast. Jij hebt het niet nodig. Claude regelt het bewaren; jij klikt in je browser. Klaar.

Python — de scripts in deze map draaien in Claude's eigen werkomgeving, niet op jouw laptop.

Een code-editor zoals VS Code — leuk als je nieuwsgierig bent, niet nodig.

Krijg je ergens het advies "installeer eerst X" en snap je niet waarom? Vraag gewoon: "heb ik dit echt nodig, of kan het zonder?" Meestal kan het zonder.

Als iets niet lukt

Dat is normaal, en het is geen teken dat je iets fout doet. Doe dit:

  1. Maak een schermfoto van wat er misgaat — toets Windows + Shift + S.
  2. Sleep hem in het chatvenster bij Claude.
  3. Typ erbij: "dit gaat mis, wat moet ik doen?"

Je hoeft de foutmelding niet te begrijpen. Dat is het hele punt.
