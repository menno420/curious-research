Eerlijk: dit is geen automatisch gedeeld geheugen

Een openbare bron maakt het mogelijk om iedere AI dezelfde invoer te geven. De AI leest hem alleen als zij webtoegang heeft en de URL werkelijk opent. Anders moet je de tekst plakken of uploaden. Een chatantwoord werkt GitHub nooit vanzelf bij.

Waarom GitHub hier handig is

Niet omdat de maker programmeur moet worden, maar omdat kennis één controleerbare plek, geschiedenis en publicatieroute krijgt.

Een goede eerste vraag

Gebruik het werkplaatsprofiel dat ik zojuist gaf. Mijn A1-print trekt linksvoor los. Geef maximaal drie hypotheses, kies de kleinste test met één variabele en vertel wat ik in Bambu Studio Preview of aan de print moet controleren. Benoem iedere aanname.

Na een geslaagde test

  1. Noteer machine, materiaal, instelling, meetresultaat en datum.
  2. Laat bepalen of het resultaat in het profiel, een gids of een projectlog hoort.
  3. Laat de wijziging als aparte branch en pull request maken.
  4. Controleer het verschil en de automatische tests.
  5. Merge pas daarna; de website krijgt vervolgens de bijgewerkte kennis.

Een eigen GitHub-account is voor deze route nu niet nodig. Later kan de maker zelf clonen en wijzigingen voorstellen; de kennisstructuur hoeft daarvoor niet opnieuw te worden gebouwd.
